# Foodmandu-Analysis: Cloud Kitchen Market Trends & Prediction

This project focuses on analyzing the food delivery ecosystem in Nepal, specifically looking at Cloud Kitchen performance and market potential using data from Foodmandu.

## 📊 Project Overview
The goal of this analysis is to identify key factors that contribute to the success of cloud kitchens and to prepare data for predictive modeling regarding market demand.

## 📂 File Descriptions
* **`foodmandu_data.csv`**: Raw dataset containing restaurant details, ratings, and pricing.
* **`cloud_kitchen_ml_ready.csv`**: Pre-processed and cleaned dataset optimized for Machine Learning models.
* **`foodmandu.ipynb`**: Jupyter Notebook containing data cleaning, exploratory data analysis (EDA), and visualization.
* **`Cloud Kitchen Expansion in Kathmandu.docx`**: A comprehensive report summarizing the market research and business insights.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Environment:** Jupyter Notebook

## 📈 Key Analysis Features
1.  **Data Cleaning:** Handling missing values and formatting restaurant categories.
2.  **EDA:** Visualizing price distributions and rating correlations across different cuisines.
3.  **ML Preparation:** Feature engineering for predicting demand or kitchen efficiency.
